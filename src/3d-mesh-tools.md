# 3D Mesh Tools

Scans rarely come out of the scanner clean, watertight or sitting square to anything. I built **3D Mesh Tools** to fix that: a free desktop program for levelling, squaring up, scaling, repairing and shrinking STL files from 3D scans, before they go into CAD or a slicer.

It comes with **3D Mesh Compare**, which lines a scan up with its CAD model and colours every point by how far it is off.

[Get 3D Mesh Tools at 3dmeshtools.com →](https://3dmeshtools.com/3dmeshtools/)

[3D Mesh Compare →](https://3dmeshtools.com/3dmeshcompare/)
